# Security reports

This repository is at the foundation-scaffold stage and has no supported
production release yet. Report suspected vulnerabilities against the current
default branch; a version-support policy will accompany the first release.

Use the repository's **Security → Report a vulnerability** option if private
vulnerability reporting is available:
[XTraceAI/xtrace-desktop security page](https://github.com/XTraceAI/xtrace-desktop/security).
This document does not assert that GitHub private reporting has been enabled.
If the option is absent, contact a maintainer through an established private
channel. If you lack one, ask how to make private contact without disclosing the
vulnerability in a public issue.

Include the affected revision, macOS version, reproduction steps, expected and
observed behavior, and likely impact. Prefer a minimal synthetic reproduction.
Do not send real credentials, personal transcripts, or an unredacted application
database. Discuss any sensitive evidence privately before transferring it.

Maintain privacy while the report is investigated and coordinate disclosure
with maintainers. Response and fix timelines will depend on the report and
maintainer availability; no security service-level agreement is offered here.
